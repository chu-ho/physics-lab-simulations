高台高度＝階梯數 × 單階尺寸；小球從邊緣 發射。理想質點、無空氣阻力與摩擦；踏面及立面皆會反彈。球體大小僅為示意。調整參數會重設紀錄。

反彈紀錄 · 時間 / x / y（m）

高台與階梯斜拋

拖曳旋轉、滾輪或雙指縮放。方向鍵也可旋轉；＋／− 可縮放。播放、暫停、單步與時間拉桿可查看每次碰撞。

每階的水平寬度與垂直高度相同。發射點 x = 0 m，高台邊緣 x = 0；階梯沿 +x 下降，延伸於 z 方向。小球沿 x–y 平面運動。

每段飛行採用 x = x₀ + vₓt，y = y₀ + vᵧt − ½gt²。碰撞時法向速度反向並乘以反彈係數 e，切向速度不變。e = 1 為完全彈性碰撞，e = 0 為無法向反彈。無摩擦、無空氣阻力；以質點計算碰撞。

橘色編號記錄碰撞位置。紀錄與 CSV 僅包含目前時間之前的碰撞；拖曳時間可重播。低速接觸踏面後停止（法向速率低於 0.08 m/s），或模擬到 30 秒／240 次碰撞上限。
