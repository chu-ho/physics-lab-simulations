## 建議（教學體驗改進）

- 用 0／1／2 數字代表模式的拉桿改成切換鈕或下拉選單，例如「模式（0 發射／1 吸收）」「路徑資訊（0 無／1 有）」「軌域（0：1s／1：2s／2：2p_z）」「陽極靶：0 Cu／1 Mo／2 Ag」「反應（0 氘氚融合／1 鈾分裂）」「核種索引（0 至 6）」「入射條件 0／1」「電壓模式 0／1」。學生看到「核種索引 3」不會知道那是 Fe-56。
- 圖表預設改成有教學意義的那張：nuclear-binding 用 B/A 對 A 曲線，hydrogen-spectrum 用能階圖或譜線位置，quantum-well 用 ⟨x⟩(t) 或某點的 |ψ|²(t)，photoelectric 維持 I–V（很好）。
- 近代實驗多半是「圖解」性質，建議預設採正對的 2D 視角（正視或俯視）並放大取景，3D 旋轉保留給想看的人。
- matter-wave 可以疊一條理論 |ψ|² 曲線在屏上，並在「路徑資訊 = 有」時同時顯示兩種結果的比較。
- blackbody 可以在光譜上標出可見光區段，以及 λ峰 的維恩位移標記。
- 入口頁：兩個搜尋框合併成一個，或同步內容；搜尋後自動捲到並展開命中的章節；「全部實驗 ↗」改為回到原本的捲動位置並保留篩選；「切換實驗」下拉選單按主線／章節用 optgroup 分組、順序與總覽頁一致。
- 入口頁「全部實驗」可以提供「精簡清單」模式（無縮圖），手機版尤其需要。

- 完全沒有問題的實驗：無。
