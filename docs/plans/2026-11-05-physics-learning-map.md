## 3. 地圖互動與視覺規格

第一版採可平移縮放的平面地圖，四大主幹各有固定區域、名稱與色彩。此選擇以閱讀層級和尋路為優先；實驗內仍使用現有 3D 操作。

1. 全圖顯示四大主幹與十九分支，所有主幹均可辨認。尚無實驗的分支顯示「規劃中」。
2. 放大章節後展開概念群與實驗節點。文字大小設下限，低縮放時折疊次要節點。
3. 選取節點後固定顯示完整歸屬路徑、先備概念、可做實驗與下一步。
4. 主幹到章節用區域及階層表達；先備概念用有向線；跨章關係在選取時展開。
5. 搜尋涵蓋實驗名稱、概念、公式常用別稱及生活情境，例如「電梯變重」「眼鏡」「磁鐵掉進管子」。
6. 保留地圖位置、縮放與選取節點，從實驗返回時恢復；支援可分享的節點定位與重設視圖。
7. 顏色搭配文字、形狀及圖例。鍵盤可選節點，手機使用階層清單和定位按鈕。
8. 明確區分「已可操作」「待改善」「規劃中」。進度不是掌握程度，不因開過實驗就標記學會。

地圖驗收採三個指定任務：找到「力學／動力學／摩擦／腳踏車摩擦」；找到「波動與光學／幾何光學／成像／透鏡遮一半」；找到尚待開發的「近代物理／光電效應」。檢查首次畫面主幹可見、搜尋定位、路徑歸屬、返回位置、手機與鍵盤操作。

## 4. 課綱與教學的使用方式

每個概念分別標示高中基礎、高中加深加廣、大一普物、進階延伸。標示需要課綱或具體課程來源支持；確認前保留「待核對」。十九分支不全部視為高中必修，也不全部視為每所大學的大一必教。

每個課綱對應記錄官方文件名稱、學習內容代碼、原文、頁碼、層級與來源連結。只有核對原始 PDF 後才填正式代碼。課程綱要到單一實驗是多對多關係，完成一個實驗不代表完成整條課綱要求。

每章採「生活問題、預測、操作、觀察、解釋、換情境」的活動模板。高中版本先以方向、比例、圖表和守恆推理；大一版本依題目加入微積分、連續分布與數學推導。數學工具以需要時的概念節點出現，例如向量、斜率、積分面積、複數相位、機率正規化。

具體課綱與課程證據見 [課綱與教學研究](physics-map-research/curriculum.md)。

本輪已核對國教院正式課綱，以及中和高中、臺大普物、北科大一年級物理與臺大電機近代物理的公開課程資料。高中課程可分必修入口及五門加深加廣；大一範圍依科系不同。臺大電機近代物理列為大二至大四選修，因此完整薛丁格方程、氫原子量子計算與半導體能帶預設標為進階。高中量子概念保留電子機率分布的定性入口。半導體的高中正式課綱對應尚未確認。附件 C1–C7 提供原始連結與各項對應。

## 5. 學生反饋的研究與轉譯

來源固定包含 Meteor、Dcard、Instagram 與 Threads；補充來源必須標示。研究以可公開核查內容為範圍。資料項目包含原始 URL、查閱日期、原文明示學段、可見原文或摘要、困難概念、上下文、去重鍵與設計含義。保留學習問題，省略帳號與不必要個資。

有效的候選困難須能寫成具體問題，例如「速度為零為什麼合力不為零」。僅說「物理很難」可記錄情緒，不能直接推導特定實驗需求。轉載、同串回覆及同一來源的重複摘要分開計算，避免灌大證據量。

證據分級為 E1 原文可讀且困難明確、E2 只讀到搜尋摘要或局部原文、E3 教學者觀察、E0 設計推論。學生需求強度、課綱重要性與可視化價值分欄，不混成「學生最想要」。現有初步來源詳見 [學生反饋附件](physics-map-research/student-feedback.md)。

後續補樣針對各章設搜尋矩陣，先廣泛掃描，再對候選首批深入。每主幹目標至少找到三種不同困難，取得不足就留下缺口。高階近代物理在高中社群的證據可能稀少，須與大學課程需求分開。新一批開發排序前重新檢查候選題是否有足以支持設計的問題描述。

## 7. 首批候選設計與物理驗收

以下為依現有覆蓋缺口提出的建議順序，學生反饋證據仍須逐題掛接。首批以既有實驗的導覽改善，加上四個新模型為可交付單位；每次開始新模型前重新核對最新登錄。

| 候選 | 操作與觀察 | 模型範圍 | 可驗證結果 |
|---|---|---|---|
| PV 路徑比較 | 改起終態與路徑，並排活塞、PV 面積、Q/W/ΔU | 定量理想氣體、準靜態分段等壓等容等溫，明示氣體作功為正 | 同起終態 ΔU 相同；W 為積分 p dV；ΔU=Q−W；閉合循環 ΔU=0 |
| 磁鐵穿線圈 | 改磁鐵方向、運動速度、匝數，觀察通量及電壓正負 | 準靜態、初版高阻量測感應電壓；閉路電流須另納入 R/L 與反作用 | 固定時感應電壓為零；反轉速度或磁極時符號反轉；ε=−N dΦ/dt |
| 串並聯與 RC | 開關、電阻、電容與電源，顯示節點電位、支路電流與能量 | 理想集中元件，先固定幾種拓樸，避免首批加入任意電路編輯器 | KCL/KVL、串並聯等效、時間常數 RC、充電極限與能量平衡 |
| 光電效應 | 獨立改頻率、光強、金屬、外加電壓，顯示截止與最大動能 | 單光子、理想材料逸出功；電流曲線若簡化須標示，光強固定能流與固定光子流分清 | Kmax=hf−φ；截止頻率 φ/h；遏止電壓 Kmax/e；閾值以下無發射 |

第二批可以同步做黑體輻射、氫原子能階、放射性衰變，三者模型依賴低且可用解析式或可重現抽樣驗證。第三批做物質波、偏振／薄膜干涉、高斯面與電容。第四批才展開量子定態與軌域、PN 接面、RLC、渦電流及熱機。這是技術與教學順序提案，並非由目前社群樣本推算的熱門排名。

所有新題都須交付「預測、操作、觀察、解釋」四步活動及一題換情境判準。例如光電效應要求學生解釋提高閾值以下光的強度為何仍無電子，而不是只讀公式。

### 進階模型的邊界

- 黑體初版輸出每單位波長光譜，切換頻率座標須含變數轉換，兩種峰值不以 λν=c 直接互換。
- 量子動畫分開 ψ 的實部／虛部與 |ψ|²；定態機率密度保持不變，軌域點雲不表達電子經典軌跡。
- 物質波的單次探測位置依機率抽樣，不能用古典微粒路線暗示量子路徑已確定。
- 半導體能帶與載子動畫標明簡化假設，PN 接面示意不得宣稱為自洽器件模擬。
- 衰變固定亂數種子可重現，單次樣本有漲落，多次平均才趨近指數規律；核反應只處理教學能量與核種守恆。

## 8. 資料與工程契約

提議以 `data/learning-map.json` 保存主題、章節、概念、先備邊及實驗映射，以現有實驗 ID 連接。實驗名稱與入口從單一登錄來源取得，避免另維護整份複本。資料欄位先限於下列需求。

- 概念有固定 ID、名稱、主分支、說明、學段、別稱與來源 ID。
- 實驗映射有 experimentId、主分支、涉及概念及狀態。
- 先備邊有 from、to、required/helpful、理由與適用學段；相關連結獨立保存，不參與先備 DAG 檢查。
- 課綱與研究來源另存參考資料，前端不載入長篇研究全文。
- 已有與規劃中節點都可見，只有有效實驗入口提供開啟操作。

先抽取 `assets/library.js` 中共用的入口解析與實驗清單，再由總覽和地圖共用；舊頁的網址和查詢參數仍須實際驗證。正式實作前以現有架構決定最小檔案拆分。

驗證包含 ID 唯一、引用存在、每個已登錄實驗有且只有一個主歸屬、先備關係無循環、孤立節點有理由、入口可開啟、搜尋別稱可定位。模型檢查沿用個別 `verify-*.cjs` 與 `verify-all.cjs`；地圖另做資料驗證及真實瀏覽器操作，不能用離線繪圖代替。

### 團隊分工與合併規則

可同步開發不代表同時修改共用入口。每位實作者擁有自己的 `models/<id>.js`、`assets/scenes-<id>.js`、`verify-<id>.cjs`、獨立入口與活動草稿。主整合者統一修改 `mechanics-models.js` 的載入、`mechanics.html`、`assets/library.js`、`docs/routes.json`、`verify-all.cjs` 與地圖主資料。內容研究先交各自分支草稿，再集中合併跨章邊。

四個工作槽可採一名整合／地圖、一名力學與熱、一名電磁、一名近代；波光先由內容研究補路徑，待力學批次完成後接續。若人力較少，沿 S0、S1、S2/S3、S4、S5–S8 順序執行即可。每批合併前重新讀最新登錄，避免其他工作已完成同題。

### 不宜同步的關鍵依賴

資料 ID 與歸屬規則必須先定案，才能批次建立映射。量子軌域需先確認機率呈現契約；PN 接面需先確定能帶／載子表示；RLC 需承接電路狀態與數值積分契約。共用介面修改與全站驗證由整合者序列執行，避免各分支以不同版本宣告通過。

## 10. 優先級與學生試用
