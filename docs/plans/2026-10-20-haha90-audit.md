# 好好玩物理網逐項檢查

## 原始目標

逐一檢查指定網站左側各類物理模擬的內容；舊版 Flash 僅截圖，不執行。交付可查閱的分類清單、內容紀錄、載入限制與截圖。

## 狀態

完成，2026-10-20（Asia/Taipei）。網站來源：使用者指定的 airplaneBoom2024 頁面之側欄。

## 目前證據與續作入口

- `research/haha90-audit/catalogue.json`：實際瀏覽器 DOM 取得的 119 個側欄項目（包含非模擬項及重複連結，需去重分類）。
- 每頁檢查結果將持續寫入 `research/haha90-audit/results.json`；截圖存 `screenshots/`。
- 瀏覽器 CUA 工作頁 auditTab，tab ID 6；續作先確認 handle 是否仍有效，失效時依目錄建立新頁，不假定仍在執行。
- 不需讀物理實驗室的全部模型，這是外部網站內容檢查，不修改模擬功能。
