# 四大主幹的課綱與教學依據

查閱日期為 2026-11-05。本文件供開發規劃使用。四主幹與十九分支採使用者指定名稱。下表的教學路徑與深度配置是專案設計建議，並非課綱原文或全國一致的授課順序。

## 已核查來源

- **C1 國教院正式課綱**。普通型高中自然科學領域，發布頁附正式 PDF。PDF 第 199–204 頁（檔案頁序）可查電磁現象、量子現象與實驗建議。量子部分包含黑體、光電、物質波、原子模型、機率分布與核衰變。電學要求涵蓋場與電位、磁效應、感應及簡單電路。 [發布頁及正式附件](https://www.naer.edu.tw/PageDoc/Detail?fid=55&id=1290)
- **C2 中和高中物理科課程頁**。提供該校必修及五門加深加廣課程內容，能核對實際高中安排。必修含運動、電磁、量子與能量的入門概念，加深加廣分力學一、力學二與熱學、波動光及聲音、電磁現象一、電磁現象二與量子現象。這是單校例證。 [課程內容](https://sites.google.com/mail2.chshs.ntpc.edu.tw/physics/108%E8%AA%B2%E7%B6%B1%E8%AA%B2%E7%A8%8B%E5%85%A7%E5%AE%B9)
- **C3 翰林高中教材章節表**。出版社第一手目錄列出運動、動量、功與能、熱學、波與光、電磁及近代物理細目，可用於核對課本術語與章節拆分。 [教材簡介](https://website.hle.com.tw/market/sh/%E6%95%99%E5%AD%B8%E7%B0%A1%E4%BB%8B/111%E7%B0%A1%E4%BB%8B%E6%9C%AC%E5%B0%81%E9%9D%A2%E6%99%AE%E9%AB%98%E7%89%A9%E7%90%86.pdf)
- **C4 臺大普通物理 103S114**。實際開放課程涵蓋運動、力、能量、動量、轉動、平衡、重力流體、振動、波、熱力學、氣體論、熵及電磁學，可作微積分普物深化參考。 [課程單元](https://ocw.aca.ntu.edu.tw/courses/103S114)
- **C5 臺大普通物理 105S111**。包含位能圖、阻尼與驅動振盪、聲波、熱過程、Carnot、熵、高斯定律、RC、磁場及電感。採課前影片與測驗、課中提問、小組解題及講評，可轉為模擬的「預測、操作、解釋」流程。 [課程與教學方式](https://ocw.aca.ntu.edu.tw/courses/105S111)
- **C6 北科大 114-1 電子一甲物理**。明示一年級工程背景，進度包含向量、運動、動力學、功與能、動量、粒子系統、轉動與角動量，振動與波視進度加入。各系普物覆蓋不同。 [實際教學大綱](https://aps.ntut.edu.tw/course/tw/ShowSyllabus.jsp?code=11067&snum=348862)
- **C7 臺大電機近代物理課程**。列為大二至大四選修，包含薛丁格方程、機率解釋、氫原子量子理論、統計、能帶與半導體。提供區分大一入門與進階的證據。 [課程資料](https://web.ee.ntu.edu.tw/course5.php?courseid=901+38100)

## 十九分支的建議深度與路徑

「高中深化」表示適合對接加深加廣內容。「大一延伸」以已查普物課程為例。「進階」需另列標籤。下列先後順序為設計提案，正式逐節課綱代碼應在實作前核對 PDF 原表。

| 分支 | 高中入口／深化 | 大一或進階延伸 | 建議概念順序 | 教學依據 |
|---|---|---|---|---|
| 1.1 運動學 | 位置、速度、加速度、拋體、相對運動 | 向量微分、曲線運動 | 座標與時間、圖像、分量、參考系 | C2、C3、C6 |
| 1.2 動力學 | 牛頓定律、摩擦、圓周、引力、動量 | 剛體轉動、角動量、阻尼與驅動 | 受力圖、運動方程、約束、系統動量 | C3、C4、C5 |
| 1.3 靜力學 | 力與力矩平衡、質心 | 分布負載、流體靜力、穩定性 | 單物體、合力、合力矩、穩定條件 | C2、C4 |
| 1.4 能量 | 功、動能、位能、守恆、功率 | 位能曲線、積分作功、非保守功 | 系統邊界、能量轉移、帳目、轉折點 | C3、C5 |
| 1.5 熱力學 | 溫度、理想氣體與氣體動力論 | 熱力學定律、熱機、熵 | 微觀碰撞、狀態、過程、循環、不可逆 | C2、C4、C5 |
| 2.1 波動的性質 | 傳播、疊加、反射、駐波、聲音 | 相量、波能流、拍頻 | 局部振動、空間波形、相位、邊界、疊加 | C2、C3、C5 |
| 2.2 幾何光學 | 折射、全反射、透鏡 | 光學系統與近軸近似的限制 | 光線、界面、像、儀器 | C2、C3 |
| 2.3 物理光學 | 干涉、繞射、電磁波偏振 | 複振幅、分辨率 | 光程、相位、場疊加、強度 | C1、C3 |
| 3.1 靜電學 | 庫侖力、場、電位 | 高斯定律、電容、介電質 | 電荷、向量場、純量位、儲能 | C1、C5 |
| 3.2 電流磁效應 | 導線磁場、磁力、帶電粒子運動 | Biot–Savart、Ampere、磁偶極 | 電流方向、磁場、磁力、軌跡 | C1、C5 |
| 3.3 電磁感應 | 磁通、法拉第、楞次、發電機 | 自感、互感、RL、場能 | 通量變化、電動勢、電流、反作用與能量 | C1、C5 |
| 3.4 電路學 | 歐姆、串並聯、電功率 | Kirchhoff、RC、交流暫態 | 節點電位、支路電流、守恆、時間響應 | C1、C5 |
| 4.1 黑體輻射 | 輻射分布與量子化起點 | Planck 曲線與極限 | 溫度、光譜、峰值、總輻射 | C1、C3 |
| 4.2 光電效應 | 光量子、頻率門檻 | I–V 與遏止電壓量測 | 頻率與強度分開控制、電子能量、光電流 | C1、C3 |
| 4.3 物質波 | 德布羅意與電子繞射 | 波包、機率累積 | 動量、波長、繞射、探測分布 | C1、C7 |
| 4.4 原子模型與波爾能階 | 散射證據、氫光譜、能階 | 模型適用範圍與量子修正 | 實驗證據、模型預測、譜線、模型限制 | C1、C3、C7 |
| 4.5 量子力學、波函數、軌域 | 電子機率分布的定性入口 | 波函數、正規化、一維定態、氫軌域屬進階 | 機率、振幅、相位、定態、軌域 | C1、C7 |
| 4.6 半導體物理 | 生活應用入口，課綱正式對應待補 | 能帶、載子、摻雜與接面屬進階 | 原子能階、能帶、載子、接面、元件 | C7 |
| 4.7 核物理 | 核組成、放射衰變、守恆 | 衰變統計、束縛能與核反應 | 單核隨機性、整體規律、半衰期、能量 | C1、C3 |

## 對開發的直接影響

1. 地圖的章節歸屬與學習前提應分開。3.3 感應依賴磁場與基本電路，即使電路排列在 3.4，也應可回查所需概念。
2. 4.3 物質波應連回 2.1 疊加與駐波、2.3 繞射。4.4 連回庫侖作用與能量，4.6 連回 4.4、4.5 與電路。
3. 每個節點標示「高中入門／高中深化／大一延伸／進階」，避免把完整薛丁格解法和半導體能帶放進所有高中學生的必經路徑。
4. 實驗先提供定性預測，再顯示數值與圖表，最後用反例或參數極限檢查理解。此為參考實際課堂模式後的設計提案。
5. 熱機、熵、高斯面、RC/RL，以及機率波函數適合分成高中直觀版與普物定量版，分別標示數學前提。
