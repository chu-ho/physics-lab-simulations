# 四大主幹的生活情境與實驗候選

查核日期為 2026-11-05。此文件提供設計提案，生活情境與控制設計由本次研究整合推導。來源支持相關物理與教學範圍，不代表已證明學生需求或教學成效。現有內容依本專案 `CURRICULUM.md` 初步比對，所有新增候選仍需核對實際模型及入口。

## 建議先後與可同步範圍

此處是依現有覆蓋與模型依賴作出的工程推論，待學生反饋與課綱研究共同排序。

1. 既有力學與波光可以同步做地圖標記、生活情境入口與探究任務，避免重製已存在的實驗。
2. 新模型可分成熱力學路徑、電流磁場／感應、直流電路／RC、黑體／光電四個工作包。各包先有獨立模型與驗證，接入共用 UI 的修改集中整合。
3. 波爾氫原子、物質波與機率模擬可在近代的參數單位、亂數回放與圖表契約固定後並行。
4. PN 接面應接在電路、電位、能階基礎之後。氫原子軌域接在機率密度之後。這是教學先備關係，模型程式開發可在介面契約確定後提前進行。
5. 核衰變與粒子偵測可共用可重播亂數的需求，但先確認現有工具能否承接，再決定是否抽共用模組。
