# 物理模擬網站 UI 與功能研究，及本站改善計畫

## 原始目標與範圍

- 使用者原始要求：整站美感與介面要改版；先研究 oPhysics、GlowScript／VPython、myPhysicsLab、「Derive」與 PhET 的 UI 與功能，再寫出具體改善計畫（本文件）。
- 本次只產出研究與計畫，**不改站點程式**；實際改版與新實驗由其他 session 執行。
- 必須保留的使用者偏好（見 [AGENTS.md](../../AGENTS.md)）：可自由旋轉縮放的 3D、拉桿調參數、播放／暫停／重設／單步／時間回放、圖表預設隱藏且展開在 3D 視窗下方、不預設顯示位置向量、沿用既有設計語言。
- 狀態：完成（研究與計畫文件；改版尚未開始）。
- 更新時間：2026-11-21（Asia/Taipei）。
- 研究方法：實際以瀏覽器開啟各站頁面讀取，並輔以搜尋；以下皆為自行歸納，不附截圖或長段引文。GeoGebra 與 PhET 的模擬本體在內嵌視窗內執行，部分細節（如 PhET 內部面板）是依官方設計文件與模擬卡片畫面判斷，已於各節標明。

### 關於「Derive」的假設

使用者拼成「Derive」，沒有名為 Derive 的知名物理模擬站（Derive 是舊的符號運算軟體）。搜尋後的候選：

| 候選 | 為何可能 | 本文採用 |
|---|---|---|
| HBCSE「[Interactive Derivations](https://lsr.hbcse.tifr.res.in/interactive-derivations/)」 | 名稱最接近，是逐步「推導」物理公式的互動系統 | **採用（主要假設）** |
| Desmos | 拼字近、用滑桿操作公式，但非物理模擬 | 僅在「公式連動」一節引用概念 |
| Physics Classroom Interactives、Walter Fendt | 常被稱為物理互動站 | 未採用 |

若使用者實際指的是別站，只需補看該站，本文第 4、5 章的結論不受影響（「推導」這個方向已由 myPhysicsLab 的推導頁涵蓋）。

## 1. 各參考站研究

### 1.1 oPhysics（ophysics.com）

- **版面**：極簡的老式網頁。頂端一列分類導覽（運動學、力、守恆、波、光、電磁、旋轉、流體、近代、繪圖工具、趣味），首頁只有說明與「最近更新」清單。每個模擬頁就是標題、GeoGebra 內嵌視窗、下方文字說明（例：[滾動與滑動](https://ophysics.com/r1.html)）。
- **控制面板**：由 GeoGebra 原生元件組成——滑桿、勾選框、按鈕直接放在畫布內，畫面與控制不分離，所以每個模擬的排版都不同。
- **字型與色彩**：白底、系統無襯線字，幾乎沒有視覺設計；吸引力完全來自內容與教師口吻（作者是退休高中教師，頁面有「感謝來信」式的社群感）。
- **參數／圖表／向量／量測**：參數靠滑桿即時改；圖表與向量由各模擬自行決定，沒有統一的圖表區與量測工具；「繪圖工具」分類另放輔助工具。
- **新手引導／說明**：每頁一段「Description」說明物理與可調項目，無互動式教學流程。
- **行動裝置**：頁面固定寬度導覽，無響應式設計；GeoGebra 視窗可縮放但操作吃力。
- **值得注意的功能**：題材貼近教學（如滾動打滑轉純滾動、U 形管密度、托里切利）；「最近更新」讓老師知道新增內容。
- **對本站的啟發**：優點是「一頁一概念＋一段說明」；缺點（不統一、不響應式）本站已經超越。可借的是「最近更新」清單。

### 1.2 GlowScript／Web VPython（glowscript.org）

- **版面**：站本身是「程式編輯器＋執行頁」。入口頁只有簡介、Help、範例連結與登入；範例以資料夾列出，點開執行（我在無登入狀態下僅確認到入口與範例清單，編輯器內部細節來自文件）。
- **控制面板**：沒有預設面板——控制項由程式用 `button`、`slider`、`checkbox`、`menu` 等指令自行建立，放在 3D 畫布上下。
- **字型與色彩**：淺藍灰頁首、白底、等寬程式碼；3D 預設背景為黑，物體為純色基本形狀。
- **參數／圖表／向量**：向量是一等公民（`arrow` 物件，長度即量值）；圖表用 `graph`／`gcurve` 與 3D 場景並列；軌跡用 `make_trail` 一行即成。
- **3D 操作**：預設即可用滑鼠右鍵／拖曳旋轉、滾輪縮放，與本站偏好一致；行動裝置可執行。
- **新手引導**：Help 文件、教學連結、可分享的程式連結；學習路徑是「看範例 → 改數字 → 再執行」。
- **值得注意的功能**：一個連結即可分享完整模擬；軌跡、箭頭、標籤成為標準詞彙。
- **對本站的啟發**：不必做程式編輯器，但「軌跡一鍵開關」「向量長度可讀」「連結即分享狀態」值得移植。

### 1.3 myPhysicsLab（myphysicslab.com）

- **版面**：首頁是長長的模擬清單；每個模擬頁（例：[雙擺](https://www.myphysicslab.com/pendulum/double-pendulum-en.html)）上方是頁籤「Sim／Graph／Time Graph／Multi Graph」，畫布佔滿，控制在畫布下方，頁面下半是完整的物理推導與說明。
- **控制面板**：參數滑桿、顯示能量／時鐘勾選、背景色（含白底／黑底／殘影）、數值解法選單（Euler、Runge-Kutta 等）、時間步長與播放倍率；「share」按鈕把目前設定編成網址；另有可開關的終端機（可用指令操作模擬）。
- **字型與色彩**：白底、深青藍標題、藍色物體與灰色桿件，座標軸帶刻度，風格像教科書插圖。
- **參數／圖表／向量／量測**：一個模擬可切換相圖、時間圖、多變數圖；可直接**拖曳物體**改變初始條件；能量顯示為同一畫布上的條形。
- **新手引導**：靠頁面下方文字——說明「可以拖曳、可以改參數」，然後把推導全文放在模擬下方；沒有互動導覽。
- **行動裝置**：版面可縮放但控制項偏小。
- **值得注意的功能**：推導與模擬同頁；數值解法可比較（看能量漂移）；混沌系統（雙擺、兩個雙擺並列比較）；「複製設定」網址。
- **對本站的啟發**：本站目前只有側欄「公式與假設」，缺少「推導」層級與「可拖曳初始條件」「可分享網址」。

### 1.4 「Derive」候選：HBCSE Interactive Derivations

- **版面**：入口是一張清單，列出「弦的振動推導、氣壓公式、熱傳導方程、黏性介質中的單擺、白努利方程」等，每項附 Live Demo 與 GitHub。頁面註明「目前只相容筆電／桌機」。
- **特色**：把「推導」做成互動——學生一步步選擇或排列推導步驟，並看到對應物理圖像（依其名稱與簡介判斷；我未能穩定載入示範本體，內部操作細節未逐一驗證）。
- **對本站的啟發**：適合做成實驗頁的「推導」子分頁，與 3D 場景以同一參數連動；這是本站相對 PhET 的差異化機會，且符合「動手＋理解」的教學目標。

### 1.5 PhET（phet.colorado.edu）

- **版面**：以[模擬頁](https://phet.colorado.edu/en/simulations/projectile-motion)為單位；頁面顯示大型預覽圖（點擊播放）、分頁「About／Teaching Resources／Activities／Translations／Credits」。模擬本身：畫布佔大部分，控制面板為右側（偶爾左側）圓角卡片，底部是播放列，右下是「重設全部」圓形黃色按鈕。
- **控制面板**：依 PhET 自家 [Look and Feel 文件](https://phet.colorado.edu/publications/PhET%20Look%20and%20Feel.pdf)，原則是：控制項少而分組、短標籤（1–3 個字最佳）、直接操作優先於面板、面板圖示化。研究也提到學生常找不到播放／暫停鈕，故它們固定放在畫面底部中央。
- **色彩與字型**：明亮的粉彩色背景、飽和色的主要控制（綠色播放、黃色重設）、大字級、重度使用圖示與色彩編碼（物理量固定顏色）。
- **參數／圖表／向量／量測**：滑桿旁直接標示數值與單位，也可以輸入；向量以勾選框開關並有固定色彩（速度綠、力紅等）；**量測工具是浮動小工具**：捲尺、碼錶、計時、可拖曳的「探針」，放在畫面角落或工具盒；圖表在獨立面板中，可展開。
- **新手引導／說明**：每個模擬有「Intro／Lab／Explore」等畫面分頁（多畫面）——從簡到繁；另有教師資源與活動單。
- **無障礙與行動**：新版模擬有鍵盤導覽、焦點樣式、螢幕閱讀器「互動式說明」與音效／聲音化；行動裝置為一等公民。
- **值得注意的功能**：多畫面分層、可拖曳量測工具、固定色彩語言、重設全部、聲音與描述、語言切換。
- **對本站的啟發**：最值得借鏡的是「畫面分層」「量測工具」「顏色語言」「大觸控目標」「鍵盤與描述」。

## 2. 本站現況（觀察紀錄）

以 `python -m http.server 8765` 在桌機與 375×812 手機視窗觀察 `library.html`、`mechanics.html#experiment=incline／doppler／rainbow`：

- **優點**：深藍灰面板（`--bg #101c25`、`--panel #172630`）、薄荷綠主色（`--mint #8ee0c0`）、橙色強調數值（`--orange #ffb36b`），場景為淺色格狀地面，與深色面板對比明顯，設計語言一致；手機上 3D 場景、數值列、播放列、參數面板自上而下堆疊，仍可用。
- **字型**：`system-ui, "Microsoft JhengHei", sans-serif`，沒有指定繁中網頁字型，不同平台字重與字距不一。
- **入口頁**：「路線圖／星圖」雙檢視與共用篩選列已完成；手機上篩選列佔去首屏大部分，實驗清單要往下捲才見到。
- **實驗頁**：右側欄參數多時需長捲動；3D 視窗上方的視角按鈕（立體、側視、俯視、正視、完整取景、跟隨物體、＋／−）排成一列，手機上換行；沒有量測工具、沒有「推導」層、沒有可分享的參數狀態。
- **發現的問題**：在同一分頁只改網址 hash（`#experiment=incline` → `#experiment=doppler`）時，頁面標題與場景**沒有切換**，要重新載入才生效；使用者貼連結或用書籤列切換時會看到舊實驗。屬功能缺陷，建議列入第 3 章 P0。

## 4. 新增實驗建議（優先順序）

### 4.1 已知課本缺口（其他 session 已在建置，此處不重複排程）

歐姆定律與電功率、安培力與電流天平、帶電粒子在電場（CRT、荷質比）、密立根油滴、X 光與布拉格繞射、3D 電磁波、功率、萬有引力（卡文迪西、g 隨高度）、量測不確定度、因次分析——**以上十項皆已有 session 在製作**。本計畫只建議它們套用第 5 章的新元件（色彩語言、量測探針、推導分頁），避免製作完再回頭改版。

### 4.2 參考站啟發的新增建議

已用目錄搜尋確認 `assets/catalog.js` 尚無下列關鍵字（雙擺、李薩如、牛頓擺、撞球、惠斯登電橋、最速降線、熱傳導、混沌、相圖）。

## 5. 全站 UI 改版計畫（交付設計師 session）

### 5.1 視覺方向

沿用「深色面板＋薄荷綠操作色＋淺色 3D 場景」，不另起爐灶；方向是**更精緻、更像一套設計系統**：

- **色彩 token（建議放 `assets/lab.css` `:root` 並供 `atlas.css`、`mechanics.css` 共用）**
  - 表面層次：`--bg #101c25`、`--panel #172630`、新增 `--panel-2 #1e303b`（浮層）、`--line #2c3d47`。
  - 文字：`--ink #ecf2f4`、`--muted #9ab0bb`（需確認對 `--panel` 的對比度 ≥ 4.5:1，不足則調亮）。
  - 操作色：`--mint #8ee0c0`（主要操作）、`--orange #ffb36b`（數值強調）。
  - **物理量固定色**（全站統一，新增）：速度＝青、加速度＝橙、合力＝紅、能量動能＝綠／位能＝紫／熱＝琥珀、電場＝黃、磁場＝藍；每種色在深淺背景都需足夠對比，並配形狀／線型當第二識別，不單靠顏色。

- **字型**：保留系統字作為備援，標題與數字改用內建可離線的單一字型堆疊（`"Noto Sans TC", "Microsoft JhengHei", "PingFang TC", system-ui`）；數值使用等寬數字（`font-variant-numeric: tabular-nums`）避免拉桿時抖動；字級以 `clamp()` 管理，內文 15–16px、標籤 12–13px，不再小於 12px。若要自帶字型須維持零外部依賴（子集化後放 `assets/fonts/`），此項屬可選。
- **間距與圓角**：以 4px 倍數；卡片圓角 12、控制項 8、膠囊 999；陰影僅用於浮層。
- **元件**：按鈕三級（主要／次要／文字）、分段控制、開關（取代部分勾選框）、數字輸入加拉桿、工具提示、抽屜、標籤膠囊（課本章節、層次）、量測工具浮層。
